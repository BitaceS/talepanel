# Examples

| Example | What it shows |
|---|---|
| [`demo/`](demo/) | The full stack on your machine with simulated Hytale servers: try every panel feature in a few minutes, no VPS and no Hytale download. |
| [`api/`](api/) | `talepanel.sh`: a small API client for scripts and cron jobs (list servers, broadcast, console commands, restart, backups, players). |

More ready-made setups (single VPS, community network with hub + gamemodes, multi-node hosting) are described in [`docs/marketing/USE-CASES.md`](../docs/marketing/USE-CASES.md).
